기록 목록

회원 모두의 기록입니다. 기록자 이름은 첫 글자만 보이고, 민감 위치는 지점 이름을 숨깁니다. ‘검토 대기’ 기록은 운영진이 확인하기 전입니다.

내 기록

운영진이 확인하기 전까지는 고치거나 지울 수 있습니다. 고치면 다시 ‘검토 대기’가 됩니다.

eBird(코넬 조류학연구소)에 올리기

내 기록을 eBird 가져오기 파일로 만들어 드립니다. eBird는 다른 프로그램이 기록을 대신 올리는 길을 열어 두지 않아서, 파일을 받은 뒤 본인 eBird 계정에서 한 번 올려 주시면 됩니다. 민감 위치로 표시한 기록과 반려된 기록은 빠집니다.

eBird 가져오기 페이지 열기 ↗

  1. 위 단추로 파일(.csv)을 받습니다.
  2. eBird에 로그인하고 ‘가져오기 페이지’에서 파일을 고릅니다.
  3. 형식은 eBird Record Format (Extended)를 고르고 Import File을 누릅니다.
  4. 장소 확인 화면에서 지점을 맞춰 주고 마칩니다. 이름이 맞지 않는 종은 eBird가 묻는 대로 고르면 됩니다.

기록 내용(조사 지점·종·개체수·메모)과 기록자 이름은 강화도습지연대의 조사 자료로 보관되며, 확인된 기록은 이름을 빼고 eBird 등 공개 조류 자료에 올라갈 수 있습니다. 탈퇴하면 기록은 남고 이름은 지워집니다. 자세한 내용은 개인정보 처리방침을 보세요.
